# Project Overview

This file is a quick reference for presenting the project in interviews.

## One-minute explanation

I built a customer churn and retention analytics project using Python, SQL, Pandas and Streamlit. I analyzed 6,000 synthetic customer records to understand which customer groups were more likely to churn and how much annual revenue was associated with churned customers. I then turned the analysis into an interactive dashboard so a business user could explore churn by contract and tenure and prioritize high-value customers.

## Main business insight

The important part of the project is not simply calculating churn. I connected churn to business impact by calculating estimated annual revenue at risk. That allows a retention team to prioritize customers based on potential financial impact.

## Technical workflow

Data -> Python/Pandas -> KPI calculations -> EDA -> SQL -> Visualization -> Streamlit dashboard -> Business recommendations
